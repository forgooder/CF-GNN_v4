# 2026-06-03 15:52 Work Report

## Scope

Added a default-off mask logit L2 regularizer and smoke-tested it on WN18RR_v4.

## Code Change

Added:

```text
--mask_logit_l2_weight
```

Default is `0.0`, so existing runs and the baseline path are unchanged.

The regularizer computes:

```text
mean(causal_logits^2) + mean(shortcut_logits^2)
```

and adds it to `mask_regularization` only when the weight is positive. The trainer logs:

```text
mask_logit_l2_loss
```
