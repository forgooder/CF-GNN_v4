# 2026-06-03 13:16 Work Report

## Scope

Added and smoke-tested a default-off effect-loss ramp. This follows the WN18RR_v2 diagnostics where hard activation at epoch 11 caused beta collapse, while a fixed lower effect weight changed the failure mode but did not make masks healthy.

## Code Change

Added:

```text
--effect_loss_ramp_epochs
```

Default is `0`, preserving the previous step behavior exactly.

Ramp behavior:

```text
current_epoch <= effect_loss_warmup_epochs:
  actual effect weight = 0

effect_loss_ramp_epochs == 0:
  actual effect weight = target effect_loss_weight

effect_loss_ramp_epochs > 0:
  actual effect weight = target * min(1, (current_epoch - warmup) / ramp_epochs)
```

The trainer now logs:

```text
effect_loss_weight
effect_loss_ramp_factor
```
