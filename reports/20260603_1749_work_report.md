## Conclusion

Disabling effect loss prevents the WN18RR_v4 post-effect scorer explosion and keeps shortcut entropy healthy through 20 epochs. Alpha is much healthier than prior effect-loss variants, though it still occasionally drifts high, including epoch19 raw causal=0.8127.

This is a useful diagnostic but not a candidate for test evaluation: validation AUC-PR remains only 0.9177, far below the WN18RR_v4 paper target and not strong enough to justify spending test budget.

## Next

The effect objective is now the main suspect for WN18RR_v4 instability. Next work should either implement a safer staged/frozen effect objective or move to NELL_v1/FB237_v1 with logit-L2 diagnostics before more WN18RR_v4 tuning.
