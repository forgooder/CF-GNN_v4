## 3. Task Goal

Address the strongest remaining v5 failure mode from WN18RR_v1:

```text
alpha/entropy collapse persists even when beta raw mask no longer collapses to zero.
```

The prior code had `--mask_entropy_weight`, but that term adds entropy to the loss and therefore penalizes high entropy. Positive values make masks harder, which is the opposite of what this stage needs.

## 4. Code Change

Added default-off entropy-floor regularization:

```text
--mask_entropy_floor_weight
--mask_entropy_floor
```

Implementation:

```text
entropy_floor_loss =
  relu(mask_entropy_floor - causal_entropy)^2
  + relu(mask_entropy_floor - shortcut_entropy)^2
```

The term is added only when `mask_entropy_floor_weight > 0`. Defaults preserve the original baseline path and all existing v5 experiment behavior.

```text

managers/trainer.py
```
