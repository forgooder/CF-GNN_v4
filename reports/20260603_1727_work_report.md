## Conclusion

Negative diagnostic. Lower LR reduces scorer explosion magnitude but does not prevent alpha saturation after effect onset. Shortcut remains healthy, so the current blocker is causal branch/scorer stability.

This configuration should not be promoted to test evaluation.
