# 2026-06-03 13:57 Work Report

## Scope

Added a default-off effect-gradient isolation option and smoke-tested `detach_shortcut`. This is a code-level response to repeated WN18RR_v2 mask collapse under scalar-only schedules.

## Code Change

Added:

```text
--effect_gradient_mode
```

Supported values:

```text
full
detach_shortcut
detach_causal
detach_both
```

Default is `full`, preserving existing behavior.

The option only changes the tensors used for training-time `effect_loss`. It does not change:

```text
model forward outputs
score_mode definitions
AUC/AUC-PR computation
MRR/Hits@K computation
test-time scoring
baseline path
```
