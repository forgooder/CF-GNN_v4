## 3. Task Goal

Run and evaluate a WN18RR_v1 anti-collapse ablation after the first formal v5 run showed late shortcut-mask collapse:

```text
causal_v5_wn18rr_v1_stronger_beta_budget
```

The goal was to test whether lower gamma, stronger mask budget, equal causal/shortcut targets, and longer effect warmup could preserve the beta/shortcut branch and improve metrics.

## 4. Commands Run

Training:

```bash
CUDA_VISIBLE_DEVICES=1 python -u train.py -d WN18RR_v1 \
  -e causal_v5_wn18rr_v1_stronger_beta_budget \
  --use_causal_training \
  --causal_loss_weight 1.0 \
  --effect_loss_weight 0.1 \
  --effect_loss_warmup_epochs 10 \
  --mask_gamma 0.5 \
  --mask_budget_weight 0.05 \
  --mask_overlap_weight 0.01 \

  --shortcut_mask_target 0.45 \
```

## 8. Conclusion

This is a formal negative result.

The beta/shortcut branch is better preserved than in the prior v5 configuration, so the specific shortcut raw mask collapse is partially mitigated. However, the model does not improve metrics, and alpha/entropy collapse persists. Stronger target-budget regularization alone is not enough.

## 9. Next Actions

Do not continue broad dataset expansion with this exact configuration.

Recommended next v5 change should target mask hardness directly:

```text
1. Add explicit entropy floor or entropy target with nonzero weight.
2. Add mask temperature scheduling or delayed hardening so masks do not saturate early.
3. Consider separate alpha and beta regularization strengths instead of one shared budget.
4. Keep WN18RR_v1 as the diagnostic dataset until AUC-PR and Hits@10 stop regressing.
```

Any next experiment should still obey the project constraints: no dataset changes, no negative sampling changes, no subgraph extraction changes, and no metric calculation changes.
