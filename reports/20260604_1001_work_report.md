## 2. Goal

Test whether a very small, delayed effect loss can recover WN18RR_v1 validation performance without reintroducing the v5 effect-loss mask collapse or scorer explosion.

## 3. Command


## 7. Conclusion

Tiny delayed effect loss does not recover WN18RR_v1 validation performance. It avoids catastrophic scorer explosion at weight 0.005 with clamp 10, but it still pushes mask health in the wrong direction: shortcut entropy drops from about 0.67 during warmup to 0.48 by epoch8, while overlap and budget penalties rise.

This path is not eligible for test evaluation.

## 8. Next Step

Do not continue this exact tiny-effect configuration.

The next WN18RR_v1 option should avoid using effect loss as a direct margin objective. Candidate directions:

```text
1. Use score_mode=causal instead of causal_plus_effect for validation with causal-only training.
2. Try a lower causal_loss_weight, because current causal-only training may over-constrain WN18RR_v1 scoring.
3. Consider an effect regularizer that controls score scale or ranking consistency without directly optimizing effect margin.
```
