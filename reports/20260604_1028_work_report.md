No test-set evaluation was run.

## 6. Interpretation

This smoke is not a formal performance result, but it is an important diagnostic signal: the original scorer inside Causal-GraIL training can have much stronger validation AUC-PR than the causal/effect score modes. The second validation point's original AUC-PR 0.9437 exceeds the same-environment WN18RR_v1 baseline AUC-PR 0.9350 and the paper AUC-PR target 0.9432.

This does not justify test evaluation yet because it is a 1 epoch smoke with batch_size 4. It does justify a controlled validation-only follow-up using `score_mode=original`, `selection_metric=auc_pr`, and all-mode logging.
