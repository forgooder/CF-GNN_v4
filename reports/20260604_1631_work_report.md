## 2. Goal

Add and smoke-test a default-off structural diagnostic for WN18RR: `masked_aux_gradient_mode=mask_only`. This mode tests whether masked causal/shortcut auxiliary losses hurt WN18RR by pushing gradients into the shared GNN/scorer.

## 3. Code change

Added:

```text
--masked_aux_gradient_mode {full,mask_only}
```

Default is `full`, preserving the existing behavior and the baseline path. In `mask_only`, the original score is computed normally, but the auxiliary masked causal/shortcut forward pass freezes non-mask parameters while building the autograd graph. This allows auxiliary masked losses to train the mask generator without sending their gradients into the shared GNN/scorer.
